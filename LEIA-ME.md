✨ FUNCIONALIDADES DO SISTEMA
==============================

O Minuta Generator é capaz de:

✓ Ler documentos: PDF, DOCX, HTML
✓ Analisar com IA: Google Gemini ou modelos locais (Ollama)
✓ Identificar padrões: Nomes, datas, números de processo, etc.
✓ Gerar templates: Com placeholders {{NOME_CAMPO}}
✓ Exportar em: HTML (visual) ou DOCX (editável)

================================================================================

💡 EXEMPLO DE USO
==================

Após instalação:

# Analisar um documento
minuta-generator generate petição.pdf -o template.html

# Combinar vários documentos similares
minuta-generator generate doc1.pdf doc2.pdf doc3.docx -o template.html

# Gerar em DOCX
minuta-generator generate documento.pdf -o template.docx --format docx

# Usar modelo local (sem necessidade de API key)
minuta-generator generate documento.pdf -o template.html --provider local
